Token কীভাবে বানাবো?
  1. github.com-এ SohaOutfit অ্যাকাউন্টে লগইন করুন।
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token।
  3. Name: soha-admin, Expiration: 1 year।
  4. Repository access: Only select repositories → sohaoutfit.github.io।
  5. Permissions → Repository → Contents: Read and write।
  6. Generate token → কপি করে এখানে পেস্ট করুন।
